# ADR-0001：独立仓库与模块化单体

状态：拟定（M0 待确认） | 日期：2026-11-01

## 背景

既有 `cold-storage-planning-agent` 是冷库规划仓库，不是运维系统或监控源码。新系统要覆盖多个工厂的全厂设备、人员巡检、报修、维修、保养与飞书入口。

## 决策

- 使用**独立仓库** `xuezhiorange-png/factory-operations-platform`。原基线建议 Private；2026-11-01 用户明确授权以 Public 提交本轮 M0 骨架。此授权不包含真实人员、设备、凭据或生产配置。
- 单仓前后端：`backend/` FastAPI、`frontend/` Vue3；独立构建单元。
- 采用模块化单体与独立 PostgreSQL；一阶段不引入微服务和重型工作流引擎。
- 业务模块各自拥有业务规则；集成通过 Adapter + Outbox，杜绝跨系统直接写表。
- M0 不部署；最终部署环境及共享入口方案仍需实际现场/现网审计。

## 后果

易统一测试/版本控制，升级和权限清晰。需要后续落实身份服务、数据库迁移、对象存储、部署回滚等基础设施。
