# 开发里程碑（基于 V1.3 PRD）

| 阶段 | 内容 | 验收出口 |
|---|---|---|
| M0 | 独立仓库/架构/CI/试点数据与监控/飞书审计 | 评审通过，无伪造外部接口 |
| M1 | 组织工厂/三角色/飞书免登/设备台账/二维码/数据导入 | 试点设备真实盘点并完成越权测试 |
| M2 | 巡检模板与版本/周期/扫码/漏检/代检/异常 | 现场按真实班次独立执行 |
| M3 | 报修/问题分诊/工单派发/接单/维修/返工/验收/飞书通知 | 闭环 MVP，在试点厂真实可用 |
| M4 | 预防保养/轻量备件/费用及服务记录 | 盘点与领退可追溯 |
| M5 | 冷库监控只读数据关联/告警去重/问题创建/统计 | 断连、重复、恢复语义正确 |
| M6 | 安全、备份恢复、培训、试点对账、跨厂推广 | 正式上线门槛通过 |

参考排期 M0 第 1–2 周、M1 第 3–6 周、M2 第 7–9 周、M3 第 10–12 周、M4 第 13–16 周、M5 第 17–19 周、M6 第 20–22 周。仅供多人并行团队估算，非承诺交期。
