# M0 开发与回滚

M0 不部署。所有命令仅针对独立开发目录；不连接任何生产系统。

## 开发进程

按 [README](../../README.md) 创建虚拟环境并安装依赖。API 使用
`uvicorn factory_ops.api.app:app --host 127.0.0.1 --port 8000`，
前端在 `frontend/` 执行 `npm ci`、`npm run dev -- --host 127.0.0.1`。
仅需 Python/Node；M0 不需要启动 PostgreSQL。`docker-compose.dev.yml` 只是未来本地数据库示例，
未在本轮运行，也不能视为数据库/迁移验证。

健康检查仅进程存活，静态构建不包含 `/api` 代理；后续测试环境需单独设计反向代理。
飞书/监控连接、secret、真实样本、备份、RPO/RTO、生产容量和证书均为 UNVERIFIED。

## 回滚与发布门槛

- 未合并的 Draft PR 可关闭或保留修订，其他系统不受影响。
- 若未来合并初始化代码后需要回退，通过新的 revert PR 撤销初始化提交，不强推、不覆盖他人工作。
- 无数据库迁移、无部署、无外部配置副作用；回滚无需操作真实数据库或生产服务器。
- 本地验证结束关闭本次启动的开发进程；不执行 `docker compose down -v` 等数据清理命令。
- main 分支保护、人工审查及 CI 必须通过后，仍需另行授权才可 Ready/合并/部署。

后续首次数据库迁移必须使用 Alembic，并在隔离环境演练升级/回滚/备份恢复。
既有冷库监控链路和控制系统在任何阶段都不受本平台初始化影响。
