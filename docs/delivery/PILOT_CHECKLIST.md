# 试点加工厂资料清单（不需要在公共仓库上传真实人员信息）

## 必需（建议先取脱敏样本）

1. 一个试点工厂名称/内部代号、区域划分（车间、冷间、机房、公辅区）。
2. 各类设备样本：编码、名称、位置、设备类型、品牌型号、投运年限、当前负责人、主要参数。
3. 现有设备台账 Excel 模板与重复编码案例，确认一码一设备/一位一码的设计边界。
4. 真实巡检记录：标准、检查项、频率、班次、执行者、漏检/代检规则。
5. 历史问题和维修记录各若干例：上报→派工→处理→验收/返工，含停机时间定义。
6. 飞书组织管理负责人、人员如何归属不同厂、普通操作工是否需要报修/巡检。
7. 监控系统实际存在的厂/房间/风机/测点编码与 API 说明（只读、脱敏）。

## 输出

- 设备类别字典与厂内编码规则（含换设备/调拨/贴码策略）
- 三种管理角色 + 业务任务执行/普通报修的授权决议
- 巡检、维修状态流的完整例外清单
- M1 数据导入规范与对账样本

**不提交**：员工身份证/手机号明文、真实飞书 token、监控系统密码、现场设备控制凭据、生产数据库转储。
