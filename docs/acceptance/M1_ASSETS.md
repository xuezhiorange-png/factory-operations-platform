# M1 设备台账最小验收集（尚未执行）

前置：只使用测试环境合成工厂 A/B、三个管理角色、无角色员工；真实试点另行授权。

| 场景 | 必须证据 |
|---|---|
| 正常建档/读取/导入确认 | 角色/授权厂正确，必填和字典校验，审计可追溯 |
| 重复确认/断网重试 | 相同幂等键同负载返回同结果，无重复资产/审计/outbox；不同负载冲突 |
| 导入错误/并发编号冲突 | 行号与错误清楚，确认事务回滚，无半成品和误发通知 |
| A 管理员或仅授权 A 的工程师访问 B | 列表、详情、搜索、导出、附件、二维码和写入一致拒绝 |
| 多厂工程师/集团负责人 | 只在合法范围访问；集团特权不绕过业务状态或独立验收 |
| 未认证/撤权/离职持旧会话 | 拒绝访问；未完成任务交接，历史身份保留 |
| 换设备、换码、移位 | 设备身份不变或明确新资产；安装区间正确；旧码撤销，旧历史可追溯 |
| 跨厂调拨 | 交接授权/集团确认，旧厂历史不被新厂越权读取 |
| 位置/机位/外部映射错误 | 同厂外键、唯一性和有效期拒绝；未知测点进入待映射 |
| 审计/outbox 写入失败 | 业务更新一并回滚；消息失败不撤销已提交业务事实，可重试补偿 |
| 非法附件或猜测对象链接 | 类型/大小/所有权校验，短期授权，跨厂链接无效 |

本轮 M0 的纯策略和健康检查通过不代表上述集成测试通过。完整现场要求见
[试点清单](../delivery/PILOT_CHECKLIST.md) 和 [V1.3 PRD](../product/PRD_V1.3.md)。
