## 飞书

- 建议：企业自建应用 / 工作台 H5 + 组织成员同步 + 机器人通知。
- 身份：后端校验官方身份凭证，绑定 `(tenant_key, app_id, open_id)` 与业务用户，不用姓名/电话猜测身份。
- 权限：飞书只认证身份，三管理角色和工厂授权均在本平台管理；部门 ≠ 加工厂。
- 员工离职/转岗：事件订阅 + 定期同步对账 + 撤会话/交接未完工单；事件来源可用性需实际验证。
- 消息：业务提交事务成功后 outbox 异步发送；幂等防重，失败重试与人工补偿，不据通知成功与否改变业务状态。
- 第一版通知卡片只有“打开业务页面”，不得直接执行设备控制或越权验收。
- 未经用户授权，M0 **不创建飞书应用，不配置租户，不读取员工数据，不发实际通知**。

官方入口：https://open.feishu.cn/

## 现有冷库监控

- 数据来源：现有监控系统的受控只读 API 或可验证事件；绝不以本冷库规划仓库代替监控源代码。
- 先审计：真实接口文档、身份授权、告警 ID、设备/机位/风机/测点编码、数据时区、断联语义。
- 映射：`source_system, external_id, factory_id, asset_id/position_id/measurement_point_id, valid_from, valid_to`，记录人工确认人。
- 传感器/通讯离线 ≠ 机械故障；告警恢复 ≠ 工单验收。
- 不访问监控生产数据库写接口；不向 PLC、HMI 或控制器下发操作。
- 接口不具备 webhook 时设计增量轮询与回补，但不能假称已存在游标接口。

## 适配端口与安全契约（仅设计，UNVERIFIED）

Application 定义端口，Infrastructure 实现；M0 不包含任何真实 SDK、URL 或凭据：

| 端口 | 输入/输出边界 | 需要验证的拒绝与重试行为 |
|---|---|---|
| 飞书身份校验 | 一次性登录凭证 → 经官方验证的租户/应用/用户标识 | 过期、重放、错误租户/应用、缺本地授权均拒绝；浏览器 OAuth state/回跳绑定 |
| 人员同步 | 已认证事件/对账快照 → 成员状态变化 | 验签/解密、防重放、乱序和重复去重；离职撤会话/权限并交接任务 |
| 通知投递 | outbox ID、内部接收人、允许的业务深链 → 投递结果 | 限流退避、超时重试、死信人工补偿；卡片打开页面后重新鉴权 |
| 监控只读查询 | 明确工厂和已确认外部 ID → 带采集时间的状态摘要 | 未授权、过期数据、断联显式标记；不伪装实时、不按名称猜绑定 |
| 监控事件读取 | 经核实的游标/时间窗 → 原始事件和下页令牌 | 只有实测支持才启用；重放/分页/乱序/补偿规则待接口确认 |

监控适配器仅具备允许的查询能力，不定义控制/复位/参数写入方法；只读身份、目标地址白名单和
受控跳转配置在 M1/M5 审核，禁止把客户端 URL 直接交给服务端请求。跳转不携带本平台会话或凭据，
不因为能够打开监控页面就声称监控已支持 SSO。

原始事件保留来源、外部事件 ID、对象编码、发生/接收时间、事件类别和原始负载引用；
优先以 `(source_system, source_event_id)` 去重，若来源无稳定事件 ID，先定义可回放去重方案再接入。
游标只在持久化原事件成功后提交；未知映射进入待映射队列，禁止直接自动建维修单。
通信离线、传感器异常、工艺报警分类保留来源语义；恢复事件仅更新关联监控事实，不能关闭问题或工单。
